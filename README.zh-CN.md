# 药品说明书检索智能体

[English](README.md)

本项目将药品说明书整理经验封装为Codex skill，强调来源证据、企业角色、原研/仿制分类与候选追踪。当前为工作流原型及离线辅助工具，不是完整自动下载平台。

## 三步来源顺序
1. NMPA/CDE原研说明书。
2. 原研企业中国官网；国外企业及监管说明书单独标为补充参考。
3. NMPA仿制药，再到厂家官网及其他可免费获取的渠道；明确具体厂家，不将仿制品当原研。

通用名、剂型、盐型、商品名和MAH须结合证据核实。企业中文联系人与国外持有人可能有关联，但不是同一法人。匹配完成后才按承办日期选择最近记录；并列保留。承办日期不代表说明书版本或批准时间。

## 安装与示例
需要Python 3.10或以上：
```sh
python -m venv .venv
python -m pip install -e .
python -m unittest discover -s tests -v
```
按操作系统激活虚拟环境。将 `skills/drug-insert-retrieval` 复制到自己的Codex技能目录。浏览器操作需另行安装Playwright CLI；Firecrawl可选，账号和额度由使用者自行配置。

调用 `$drug-insert-retrieval`，提供本地清单和输出目录即可。`examples/` 使用完全虚构的药名、企业和保留域名，不代表真实检索结果。

本地PDF检查：
```sh
python scripts/inspect_pdf.py /path/to/local-label.pdf
```
只验证可解析性、页数和哈希，不自动证明原研身份或药品匹配；扫描件需渲染核查。

## 技术架构与完成情况
输入清单 → 产品证据匹配 → 分级检索 → 候选详情 → 下载 → 文件及身份核查 → 断点和报告。

skill负责指导智能体执行；Playwright CLI负责浏览器DOM/网络检查，Firecrawl可辅助搜索。Python实现离线日期选择、哈希、缓存校验、原子检查点及本地PDF检查。

历史本地试验曾完成有界面CDE查询、部分详情页及个别下载，但真实清单、日志和PDF均不公开，不代表当前接口稳定或所有药物可获取。仓库尚未提供稳定独立CDE API、自动企业识别、无人值守全量批处理、完整续跑编排或Python Excel导出管线。工作流中的Excel交付由智能体可用的表格工具处理。访问超时不能判为未找到；职业身份声明不得冒认。
