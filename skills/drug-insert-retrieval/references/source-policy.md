# 中文说明书来源策略

## 优先级与准入分离

检索及采纳优先顺序：NMPA/CDE原研 → 原研中国官网 → NMPA/CDE同剂型仿制 → 仿制厂家官网 → 医院/可信机构 → 其他公开来源。优先级不构成候选发现的域名白名单。项目明确排除的数据库（包括丁香园）、付费、会员或访问受限内容不进入抓取及下载；不得通过第三方镜像规避。已排除记录仍留审计原因。

仅中文正文符合本任务语言范围，中英文对照药名或英文商标不影响中文文件纳入。外文正文归为REJECTED，理由NON_CHINESE_BODY，不能归入“来源待确认”。无法判断正文语言时留待核验。不得凭域名、文件名或汉字比例自动认证内容。

## 广泛候选发现

优先渠道没有合格中文文件时执行以下组合，缺失字段跳过，不编造：

- 通用名＋说明书＋PDF
- 商品名＋说明书下载
- 通用名＋上市许可持有人＋PDF
- 商品名＋批准文号＋说明书
- 规范药品名称＋中文说明书

允许未知域名、CDN和第三方公开PDF。记录实际结果URL、查询词、时间与来源，不猜附件路径。先留候选，再核对公开访问条件；搜索摘要不证明完整性、访问许可或最终匹配。

## 未知PDF来源追溯

先检查页面公开条款及访问条件。未确认下载、核验和使用符合条件时，只保留链接与候选元数据，暂停文件获取；不得把HTTP 200或“免费下载”当成使用/转载授权。可在符合条件的情况下获取候选用于核验；此时允许DOWNLOADED与UNKNOWN来源并存。

对允许获取或已合法取得的PDF：

1. 保存公开HTTP元数据（如Content-Type、文件名、Last-Modified）与PDF元数据（标题、作者、创建/修改日期）；这些均是线索，不是版本证明。
2. 提取通用名、商品名、剂型/盐型、批准文号、MAH和生产企业。扫描件渲染核对，提取不到不等于无内容。
3. 搜索实际URL、解码文件名、文档标题、批准文号，定位原始发布网页；保留真实跳转及引用链。
4. 核对发布机构、域名/CDN关联和药品企业角色。企业名称出现在PDF正文中，不证明上传者是该企业。
5. 交叉核对官方产品信息、注册信息或官方说明书。记录一致字段和差异，不把受理记录当批准证据。
6. 记录发布授权及再分发许可的原文、出处、适用文件和日期。没有发现许可记UNKNOWN，不能推断PERMITTED。
7. 仍无法追溯时保留候选、原链接、哈希、核验结果和追溯尝试，进入人工队列，继续寻找可信源；不得直接丢弃或标官方。

## 独立状态和采纳

| 字段 | 枚举 |
|---|---|
| file_status | DOWNLOADED / DOWNLOAD_FAILED / INVALID_FILE；未尝试时空值 |
| content_status | VERIFIED / NEEDS_REVIEW / REJECTED |
| source_status | OFFICIAL / VERIFIED_INSTITUTION / THIRD_PARTY / UNKNOWN |
| access_status | FREE / RESTRICTED / UNKNOWN |
| redistribution_status | PERMITTED / RESTRICTED / UNKNOWN |

另记language、complete_formal_label、product_identity_verified、source_evidence、access_terms_confirmed、download_use_allowed、redistribution_evidence、upstream_urls、trace及最终采纳决定。下载/解析成功不改变来源或授权状态；本地PDF检查器一律不能单独把内容或来源认证为VERIFIED/OFFICIAL。

默认最终采纳：中文正式完整说明书、产品身份核验通过、下载及使用符合条款、文件下载且核验成功、来源为有证据的官方或可信机构。第三方文件保留在候选中，可在项目明确采纳规则及证据充分时纳入；UNKNOWN来源始终进入人工队列，不能自动最终采纳。源优先级仅在合格候选间排序。

原研/仿制分类与来源独立：第三方可转载原研说明书，企业官网也可发布仿制药。地区与正文语言独立：中文境外说明书仍须注明地区及不代表中国获批。

公开发布另行核对再分发许可。默认本项目GitHub不上传任何说明书、真实任务清单或候选任务数据；即使may_publish为真也仅表示文档许可条件达到，不是自动上传授权。UNKNOWN或RESTRICTED再分发状态不公开上传。不得凭免费访问推断版权许可。

## 本仓库实现边界

`src/drug_label_agent/source_policy.py`提供离线枚举、广泛/追溯查询构造、严格规范产品身份比较和基于已记录证据的决策；不自动联网溯源、不验证证据真伪、不执行下载或GitHub上传。`scripts/inspect_pdf.py`提供解析、公开元数据及身份字段线索；线索仍需人工/智能体核对。先在调用方明确规范产品身份，不能把查询扩展词直接当匹配产品。
